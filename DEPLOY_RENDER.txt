Render / GitHub 部署說明

正確上傳方式
- GitHub repo 根目錄必須直接看到 index.html、server.js、package.json、assets。
- 不要把整個外層資料夾拖進 GitHub，否則 Render 會找不到正確入口。

GitHub 根目錄應包含
- assets/
- dist/windows/LuxFatum.exe
- dist/windows/Microsoft.Web.WebView2.Core.dll
- dist/windows/Microsoft.Web.WebView2.WinForms.dll
- dist/windows/WebView2Loader.dll
- index.html
- server.js
- package.json
- release.json
- render.yaml
- Dockerfile
- README.txt
- README_WINDOWS.txt
- DEPLOY_RENDER.txt
- rules_v4_1.txt
- start_server.bat

注意
- v4.2.1 之後 Windows 下載版是本地桌面應用程式，需要上傳 dist/windows 內的 LuxFatum.exe 與 WebView2 DLL。
- Windows 下載版不需要 Node.js，因此不用上傳 runtime/node.exe。

Render 部署
1. 到 https://render.com。
2. New + Blueprint，選擇這個 GitHub repository。
3. Render 會讀取 render.yaml 建立 Web Service。
4. 部署完成後檢查：
   https://你的網址/api/health
   https://你的網址/api/version

下載入口
- /download/windows.zip：Windows 玩家下載版。
- /download/package.zip：Render/GitHub 上傳包。

版本管理
- package.json 與 release.json 目前版本為 4.2.1。
- release.json 的 minSupportedVersion 控制最低支援版本。
- release.json 的 forceUpdate 設為 true 後，舊版會顯示強制更新。

房間系統
- 房間對戰 API 不變：/api/create、/api/join、/api/state。
- Windows 下載版會在本地桌面視窗載入遊戲，並直接連到 Render 線上房間 API。
